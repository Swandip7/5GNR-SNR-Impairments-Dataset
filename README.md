# 5GNR-SNR-Impairments-Dataset
100K-sample dataset for 5G NR SNR estimation across 4 CDL channel profiles (3GPP TR 38.901) with 6 realistic RF impairments (Doppler, phase noise, PA nonlinearity, IQ imbalance, colored noise, interference) and classical estimator baselines (LS/ML/EVM/M2M4/Rao/DD). 22 features/sample.
